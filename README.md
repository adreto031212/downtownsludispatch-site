# downtownsludispatch.com

Static landing site for the Downtown & South Lake Union Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py downtownslu` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `downtownslu-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
